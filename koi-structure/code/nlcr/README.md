# Реализация разреженного представления канала

Пакет MATLAB реализует два алгоритма для модели Y ≈ F(R,S,C)Z. Первый обновляет обучаемые множители совместно. Второй отдельно оптимизирует S и повторяет эту оптимизацию при проверке каждого кандидата R,C. В обоих случаях веса фиксируются внутри внешней итерации, Z пересчитывается методом сопряжённых градиентов, а удалённые коэффициенты остаются нулевыми.

Это реализация для проверки. MATLAB R2024b в текущей среде завершает запуск ошибкой `File system inconsistency` до выполнения команд. Статический анализ MATLAB выполнен; запуск `test_nlcr` ещё необходим. Отдельная проверка формул в NumPy дала максимальное относительное расхождение градиентов с конечными разностями 3.01·10⁻⁹. Она не проверяет исполнение MATLAB-кода. Серия реалистичных каналов не запускалась.

Для SemiDFT обязательно передать `axesT` и `axesN` длины r. Они задают размеры осей сеток наблюдений и словаря; произведения элементов должны равняться числу строк Y и N соответственно. Например, `[16 16]` допустим для `axesT` только при `size(Y,1)==256`, а для `axesN` — при N=256. При r=8 можно передать `2*ones(1,8)`; код проверяет произведения отдельно. Первая координата меняется быстрее. В блочном режиме r означает размер каждого из двух блоков; SemiDFT задаёт фазовый блок, амплитудный начинается с S₂=0 и случайных R₂,C₂.

## Параметры и выбранные численные правила

`nlcr_options()` возвращает все настройки. `N` и `r` обязательны для запуска. Неизвестные поля отклоняются. Следующие значения выбраны в реализации для воспроизводимости и не заменяют согласование параметров исследовательской серии.

| Параметры | Значение или правило |
|---|---|
| `maxIterations` | 64 внешние итерации; отсутствие принятого шага не завершает цикл |
| `lambda`, `epsilon`, `tau` | Порядок Z,R,S,C; по умолчанию `[.01 0 0 0]`, `[.01 .01 .01 .01]`, `[.01 0 0 0]` |
| `reweighted`, `quadratic` | Четыре переключателя; для Z обязательно перевзвешивание и нет отдельного квадратичного штрафа в целевой функции |
| `initialZ` | По умолчанию нулевая матрица; все её координаты изначально разрешены |
| `seed` | 1 для отдельного генератора инициализации; не привязан к номеру канала |
| `cgTolerance`, `cgMaxIterations` | 10⁻¹⁰, 1000; начальная точка решения каждой системы нулевая; диагональное предобусловливание |
| `learningRate`, `backtrackFactor`, `maxBacktracks` | Начальный шаг 1; уменьшение вдвое; до 30 кандидатов; принимается Φ′≤Φ |
| `innerMaxIterations`, `innerTolerance` | Для S во втором алгоритме: до 20 шагов; допуск 10⁻⁶ по норме допустимого градиента или относительному уменьшению функции |
| `real`, `train` | Три переключателя в порядке R,S,C; вещественность и обучение соответственно |
| `unitR`, `unitC`, `orthogonalR`, `orthogonalC` | Единичные нормы всех столбцов R и строк C либо их ортонормированность |
| `diagonalS`, `fixedIdentityS`, `block` | Диагональная S, фиксированная единичная S, разделение фазы и амплитуды |
| `initialModel` | Структура с R,S,C заданных исходных размеров; должна уже удовлетворять ограничениям; сохраняется без преобразований |

Режим λ₀=0 отклоняется: реализация рассчитана на положительно определённую систему. Неуспех сопряжённых градиентов в текущем состоянии завершает запуск со статусом сбоя; у пробного кандидата он ведёт к уменьшению шага. Перед вычислением метрик выполняется одно обновление D_Z и одно решение для Z после последнего удаления. Повторного удаления нет. После этого решения проверяются превышение порога нормированной ошибки восстановления (NME), заданного maxNME, и превышение допустимого числа ненулевых строк Z, заданного maxComponents. По умолчанию пороги равны 2 и 100. Возвращаемые численные метрики сохраняются и при превышении этих порогов. При сбое решателя итоговая NME равна NaN, чтобы не выдавать промежуточное восстановление за окончательное.

В `cost` считаются завершённые вычисления функции, решения систем и итерации сопряжённых градиентов; трудозатраты внутри оборвавшегося вычисления не включены. Число отклонённых по численным причинам кандидатов хранится отдельно. `seconds` измеряет работу после инициализации. `history` содержит значения функции до и после поиска шага, его результат и размеры после удаления. Убывание относится к поиску шага при фиксированных весах; оно не заявляется после смены весов или удаления.

## Инициализация и ограничения

Поддерживаются Uniform, Randn, ComplexUniform, ComplexRandn, DFT и SemiDFT. Комплексные случайные варианты используют две независимые части без деления на √2. Разложение на ортонормированный и верхнетреугольный множители (QR) с поглощением второго множителя в S выполняется перед сингулярным разложением (SVD). Для диагональной S сингулярные векторы поглощаются в R и C.

Если такое преобразование нарушает смешанные условия вещественности или нормы, применяется непосредственное приведение исходных матриц к ограничениям. Изменение Q отражается в `initializationNote`. Для фиксированной единичной и блочной S используется непосредственное приведение: сохранение исходного Q в этом случае не обещается. Невозможные размеры ортонормированного базиса и нормировка нулевого вектора приводят к явной ошибке. Сами ограничения не отключаются.

После шага ортонормированность восстанавливается полярным разложением через SVD; отдельные нормы — делением на длины. Полная блочная схема хранится как R=[R₁,R₂], C=[C₁;C₂], S=diag(S₁,jS₂), с вещественными R,C,S₁,S₂. Включение вещественности собранной S обнуляет её амплитудный блок; сочетание блочного режима с фиксированной единичной S отклоняется. Ортонормированность собранных R,C относится сразу к обоим блокам.

## Удаление

Порог применяется только к множителям с включённым перевзвешенным штрафом; фиксированные множители поэлементно не обнуляются. Для каждого множителя используется собственный максимум модуля и строгое сравнение с порогом. При нулевом максимуме деление пропускается. Обработанные нулевые элементы Z закрепляются маской, включая точные нули, полученные решением системы. Нули начальной оценки до первой процедуры удаления свободны.

Полностью нулевая строка Z удаляется вместе с соответствующим столбцом C. Нулевые строки S удаляются вместе со столбцами R, нулевые столбцы S — со строками C. Сохраняются исходные номера атомов и внутренних компонент. Для обычной S допустимы разные числа строк и столбцов.

Специальные правила требуют явного выбора `prunePolicy`:

- `ordinary` — обычная прямоугольная S; значение по умолчанию.
- `paired` — для диагональной или единичной S удаляются согласованные пары внутренних индексов. Без явного выбора этого правила такая конфигурация отклоняется.
- `blockwise` — для блочной S строки и столбцы удаляются внутри соответствующих блоков; размеры блоков могут стать различными. Метки блоков сохраняют нулевые межблочные связи. При дополнительной диагональности сохраняются согласованные пары индексов.

Это реализованные варианты политики, которые ещё нужно выбрать для исследования. В частности, целиком нулевой амплитудный блок может быть удалён после шага; отключённая или не начавшая обучаться амплитудная часть не сохраняется искусственно.

После удаления код заново приводит R,C к включённым ограничениям. Это может изменить Q, а нули самих R,S,C не считаются закреплёнными. Если атомов осталось меньше, чем необходимо для ортонормированных строк C, запуск получает статус сбоя. При полном удалении атомов представление пустое, восстановление нулевое, NME=1, корреляция не определена. После изменения размеров память оптимизатора сбрасывается.

## Обработка градиента

`None` использует отрицательный полный допустимый градиент. `AdamW` в этой реализации хранит комплексный первый момент и вещественный второй момент |G|², применяет поправку смещения и отдельное уменьшение множителя с коэффициентом `weightDecay`. Значения β₁=0.9, β₂=0.999, ε=10⁻⁸, `weightDecay=0` выбраны по умолчанию.

`Muon` здесь означает явно выбранный комплексный вариант: экспоненциальный момент β₁=0.9, затем его полярный множитель по точному SVD без нулевых сингулярных направлений. Ускоренное приближение Ньютона — Шульца, масштабирование по размерам и упреждающий момент не используются. Название не означает совпадения с любой внешней реализацией Muon. Оба варианта пропускают направление через ограничения и общий поиск шага по Φ. Если направление не является направлением спуска, используется отрицательный допустимый градиент. Моменты обновляются только после принятия шага.

Во внутренней задаче S используется обычный допустимый градиент. Каждый кандидат R,C начинает внутреннюю оптимизацию с одной и той же текущей S. При конечном числе внутренних шагов внешнее направление вычисляется по частной производной в полученной S; зависимость траектории внутреннего решателя от R,C не дифференцируется. Поэтому для второго алгоритма не заявляется точный градиент редуцированной задачи при неточной минимизации S. Фактическое принятие кандидата всё равно проверяет полную функцию после повторной оптимизации S.

## Вывод производных

Используется соглашение dΦ=Re tr(G_Xᴴ dX). Маска и веса фиксированы. Для столбца m обозначим разрешённый словарь через F_m, коэффициенты через u_m, веса через W_m>0. Тогда A_m=F_mᴴF_m+W_m, b_m=F_mᴴy_m, A_mu_m=b_m.

Часть функции данных равна f₀=−Σ b_mᴴA_m⁻¹b_m. Дифференцирование даёт

\[
df_0=-2\operatorname{Re}\sum_m(y_m-F_mu_m)^H(dF_m)u_m.
\]

Эквивалентно f₀=min_Z L(Z)−‖Y‖², где L=‖Y−FZ‖²+Σu_mᴴW_mu_m. Зависимость Z(F) уже учтена, и

\[
G_F=-2(Y-FZ)Z^H.
\]

При Q=RSC нормированный словарь вычисляется устойчиво:

\[
a_{tn}=2\pi(\operatorname{Im}Q_{tn}-\max_p\operatorname{Im}Q_{pn}),\qquad
F_{tn}=\frac{e^{a_{tn}}e^{-j2\pi\operatorname{Re}Q_{tn}}}{\sqrt{\sum_p e^{2a_{pn}}}}.
\]

Вычитание максимума не меняет F. Из дифференциала нормировки

\[
dF_{tn}=F_{tn}\left[-j2\pi dQ_{tn}-2\pi\sum_p|F_{pn}|^2\operatorname{Im}dQ_{pn}\right]
\]

следует, при h_n=Σ_t Re(conj(G_F,tn)F_tn),

\[
G_Q=j2\pi\left(G_F\odot\overline F-|F|^2\odot(\mathbf1h)\right),
\quad G_R=G_Q(SC)^H,\quad G_S=R^HG_QC^H,\quad G_C=(RS)^HG_Q.
\]

К каждому G_X прибавляется 2H_X⊙X, где H_X=a_Xλ_X/(|X^(q)|²+ε_X)+b_Xλ_X. Это производная суммы двух включаемых квадратичных штрафов при фиксированных весах.

Для вещественного множителя берётся Re G_X; для диагональной S — только диагональные координаты, для фиксированной S направление нулевое. В блочном режиме производные по фазовому и амплитудному S равны Re G_S,11 и Im G_S,22 соответственно; по вещественным R,C берётся вещественная часть соответствующих блоков градиента. Межблочные координаты запрещены.

Для столбца x единичной евклидовой нормы проекция равна g−x Re(xᴴg). Для строки единичной евклидовой нормы используется та же формула после сопряжённого транспонирования. Для ортонормированных множителей:

\[
\Pi_R(G)=G-R\operatorname{sym}(R^HG),\qquad
\Pi_C(G)=G-\operatorname{sym}(GC^H)C,\qquad
\operatorname{sym}(A)=(A+A^H)/2.
\]

Это ортогональные проекции на касательные пространства в евклидовой метрике. Возврат к ограничениям после шага выполняется отдельно. Маска, удаления и смена весов не дифференцируются. При неточном решении для Z формулы вычисляют приближённый градиент; точность контролируется невязкой системы.

## Метрики и проверка

Основная метрика NME=‖Y−FZ‖/‖Y‖. Дополнительная корреляция равна |tr(YᴴFZ)|/(‖Y‖‖FZ‖). Нулевой исходный канал отклоняется. Нулевое восстановление имеет NME=1 и корреляцию NaN; само по себе отсутствие корреляции не исключает определённую NME из среднего. `nlcr_series` усредняет NME по успешным запускам, а корреляцию — по успешным запускам с определённой корреляцией; оба числа наблюдений сохраняются. Для парных разностей используются общие успешные каналы. Эти правила особых случаев явно выбраны в коде; для исследовательской серии их ещё нужно утвердить.

`test_nlcr.m` содержит проверки полных комплексных градиентов, сравнение сопряжённых градиентов с прямым решением, нормировки при больших мнимых смещениях, QR/SVD, SemiDFT, двух алгоритмов с тремя оптимизаторами, норм и структур, маски, строгих порогов, финального обновления весов и усреднения сбоев. `check_gradient_reference.py` независимо проверяет формулы через плотные системы в NumPy. Его результат сохранён в `gradient_reference_evidence.json` и не является результатом запуска MATLAB-тестов.

Основание реализации: отчёт карточки «Базовая база» метода «Разреженная аппроксимация MIMO-канала», включая согласованные правила разреженности, нормировки и завершения алгоритма.
