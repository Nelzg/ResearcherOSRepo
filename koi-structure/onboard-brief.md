## Ответы пользователя

Описание проекта

Пусть Y = F(R, D, K)Z, где Z\in C^{N x M} - разреженное представление Y. F = softmax(-1j2\pi RDK) - матрица столбцы которой представляют собой комплексную версию softmax, R \in C^{T x r}, D \in C^{r x r}, K \in C^{r x N}. Я хочу исследовать возможность представления MIMO канала Y с помощью R, D, K и Z = (F^HF+\lambda D)^-1F^HY (решается с помощью метода CG), где D = diag{1/(|Z_1|^2+\epsilon), ..., 1/(|Z_N|^2+\epsilon)}. Базовая оптимизационная функция для нахождения R, D и K: -trace{Y^HF(R, D, K)Z}. Одной из целей исследования является поиск ограничений на R, D, K, чтобы итоговая ошибка ||Y-FZ||^2_2 была минимальной. Градиентная оптимизация должна включать различные методы оптимизации градиента такие как AdamW, Muon, dog-leg. Сама модель Y=FZ является обобщением модели нелинейного преобразования фурье, где r = 1, D = 1, R = [0, 1,..., T-1]^T, K = [k_1, k_2, ..., k_N] \in [0, 1]^{1 x N}, а сам метод оптимизации это частный случай метода TD-SURE-IR. Одним из направлений исследования является проверка свзи представления Y=FZ с современным представлением Attention для нейронных сетей. Реалистичный MIMO канал можно получить из скрипта MATLAB в репозитории. Исследование должно включать проверку различных вариаций инициализации R, D, K. Возможные дополнительные ограничения включают, но не ограничиваются, а также могут составлять комбинации min ||R||_0; min ||K||_0; min ||D||_0; R^HR = I; K^T^HK^T = I; D = diag{d}; один или несколько параметров R,K,D \in R; ||R(:, i)||_2=1; ||K(i, :)||_2=1. Также следует проверить тот факт, что часто спектр R напоминает спектр исходного канала Y, это должно натолкнуть на мысли о дополнительных ограничениях.
